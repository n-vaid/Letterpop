# Letterpop

Type anything and turn it into bubble letters, flower letters, gummy candy, stickers, neon pixel or risograph print. Save as PNG.

An exploration by [Navneet Vaid](https://navneetvaid.design), inspired by [Type Garden](https://type-garden.vercel.app) by Akshat Agarwal.

- `index.html`: the whole site
- `api/visit.js`: the visitor counter (needs an Upstash Redis database connected in Vercel)
